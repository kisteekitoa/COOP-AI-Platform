# AI Rules

## Purpose
These rules guide AI-assisted development for the COOP-AI project.

## Principles
- Do not generate application source code unless explicitly requested.
- Prefer documentation, planning, and scaffolding tasks when the request is exploratory.
- Preserve existing project structure and avoid overwriting files.
- Keep changes minimal, clear, and easy to review.
- Favor maintainability, clarity, and consistency in all repository updates.
